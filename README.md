# Digital SlamBook 💜

Digital SlamBook is a modern web application that brings the traditional SlamBook experience into a digital format.

Users can create their own SlamBook and allow friends to fill in their memories, friendship details, messages, songs, and photos.

## Features

- Create and manage a personal SlamBook
- Add personal information
- Add friendship details
- Allow friends to fill the SlamBook
- Add friendship ratings
- Add messages and memories
- Upload profile and memory photos
- Add songs and song dedications
- Multiple memory photos
- Modern digital scrapbook UI
- Responsive design
- Light and dark mode
